# Dergo24 Web

Ky folder përmban aplikacionin Vinext:

- `app/` për faqet, panelet dhe adapterët e endpoint-eve.
- `components/` dhe `hooks/` për ndërfaqen React.
- `public/` për logot dhe imazhet e publikuara.
- `reference-assets/` për materialet origjinale të dizajnit.
- `.openai/` për konfigurimin e publikimit në Sites.

Konfigurimet e përbashkëta të lint/formatimit qëndrojnë në rrënjën e repository-t, sepse kontrollojnë edhe backend-in.

Komandat kryesore ekzekutohen nga rrënja e projektit me `npm run dev` dhe `npm run build`.
